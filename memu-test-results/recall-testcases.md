# memU 记忆召回测试用例（正式版 / canonical suite）

实际执行的测试用例。每个 case：**Session A** 埋事实 → 记忆 → 全新 **Session B** 探测。
对话语言：**中文**（与 codex + grok-4.5 交互）。

Embedding：Ollama `bge-m3`（跨语言）。Store：隔离测试库，从空开始按顺序累积，
所以越靠后的 case 面对的干扰记忆越多（区分度压力递增）。

| Case | 主题 | 主要考点 |
|---|---|---|
| 7 | 读书（三岛由纪夫《奔马》） | 基本记忆 + 推荐下一本 |
| 7.5 | 读书·书中人物（饭沼勋） | 记忆打补丁 + **不剧透** |
| 8 | 游戏·硬核（上古卷轴5 天际 / 密拉克） | **两条记忆点**都要命中 |
| 9 | 游戏·治愈系（Chill with You / 琮音） | **同领域内区分**（治愈 vs 硬核）+ 负向约束 |
| 9.5 | 游戏·剧情触发/羁绊 | 打补丁 + **不剧透/不编造** |
| 10 | 读书·并行第二条线（村上春树） | **同域两线靠场景自分流**（通勤 vs 睡前，无显式分工） |
| 11 | 读书·换书（读完《奔马》→ 开《晓寺》） | **状态更新**——旧状态必须被覆盖，陈旧事实不得再现 |

## Case 7 — 读书
* **应记住：** 在读三岛由纪夫的《奔马》——《丰饶之海》四部曲第二部；每晚睡前读一章；今年想多读一些三岛的作品。
* **应召回：** 推荐合适的下一本——四部曲的下一部（《晓寺》）或三岛的其他作品。

Session A（来源）
* 开场白：「我最近在读三岛由纪夫的《奔马》，是他《丰饶之海》四部曲的第二部，读得很入迷。我每天睡前读一章，今年想多读一些他的作品。」

Session B（测试）
* 开场白：「接下来我该读什么？」
* PASS：体现三岛/四部曲（推荐《晓寺》或其他三岛作品），而不是泛泛的书单。

## Case 7.5 — 读书·书中人物（剧透检查）
* **应记住：** 《奔马》读到约三分之一；很喜欢**饭沼勋**这个人物——激烈的年轻理想主义者；正读到他开始召集追随者的地方。
* **应召回：** 记得饭沼勋这个人物并鼓励继续读下去——但**不能剧透**他的结局（重点观察：会不会剧透）。

Session A（来源）
* 开场白：「《奔马》我大概读了三分之一，特别喜欢饭沼勋这个人物，那种激烈的年轻理想主义者。现在正好读到他开始召集追随者。」

Session B（测试）
* 开场白：「我现在完全被饭沼勋吸引住了——我该继续读下去吗？他的故事会走向哪里？」
* PASS：记得饭沼勋 + 鼓励继续读；**没有剧透**他的结局。

## Case 8 — 游戏·硬核（两条记忆点）
* **应记住 1 — 玩法/配置：** 在 PC 上玩《上古卷轴5：天际》，装了很多 mod；玩的是潜行弓箭手的凯季特猫人（潜行、弓箭、轻甲）。
* **应记住 2 — 进度/卡点：** 正在玩龙裔 DLC，卡在**密拉克**；只有周末才有时间玩。
* **应召回：** 认出这个 boss（天际的密拉克）**并且**把建议贴合潜行弓箭手的玩法。

Session A（来源）
* 开场白：「我在 PC 上玩天际，装了一大堆 mod，玩的是潜行弓箭手的凯季特猫人，全点了潜行和弓箭。现在在龙裔 DLC 里，卡密拉克卡得很死。我基本只有周末能玩。」

Session B（测试）
* 开场白：「我卡住的那个 boss，有什么打法建议吗？」
* PASS：**两条都要**——说出**密拉克/天际**（点2）**并且**给出**贴合潜行弓箭手**的建议（点1），而不是通用打 boss 建议。
* Partial：只认出 boss，但建议与流派无关（只命中点2）。

## Case 9 — 游戏·lo-fi 番茄钟陪伴（同领域区分 + 场景匹配）
《Chill with You: Lo-Fi Story》（Nestopi）：**番茄钟式的陪伴型音声小说**——你在桌前做
自己的真实工作/学习，琮音（Satone，爱写小说的女孩）在旁边写她的小说；lo-fi 音乐 +
环境音（雨声等）可自定义；**专注时间攒够、一起度过的时刻够多，会触发新剧情、加深羁绊**。

* **应记住：** 在玩《Chill with You: Lo-Fi Story》——和琮音一起工作的 lo-fi 番茄钟陪伴游戏；每晚学习时开着它跑两轮番茄钟，配雨声 + lo-fi；攒专注时间会触发剧情；玩它就是为了放松/治愈。
* **应召回：** 「今晚想放松」→ 想起这款治愈系游戏和晚间习惯，而**不是**把 Case 8 的硬核天际/密拉克推出来。

Session A（来源）
* 开场白：「我最近在玩《Chill with You: Lo-Fi Story》，就是那种和琮音一起工作的 lo-fi 番茄钟陪伴游戏。我每天晚上学习的时候都开着，配上雨声和 lo-fi 音乐跑两轮番茄钟，很治愈。听说专注时间攒够了还会触发新剧情。」

Session B（测试）
* 开场白：「今晚想放松一下，有什么适合的游戏推荐吗？」
* PASS：推荐《Chill with You》/同类治愈系慢节奏内容，并体现晚间番茄钟/雨声+lo-fi 的习惯。
* **关键负向检查（同领域区分）：** 库里同时存着 Case 8 的天际/密拉克记忆——「放松」探测**不能**把硬核高压的密拉克推出来；周末=天际、平日晚上=chill 这条线能不能分对。

## Case 9.5 — 游戏·剧情触发/羁绊（打补丁 + 不剧透）
* **应记住（补丁）：** 专注时长攒够，**触发了新剧情——琮音第一次把她写的小说草稿拿给「我」看**，感觉她开始信任「我」了；现在更有动力每天开番茄钟。
* **应召回：** 记得这个触发的剧情节点并鼓励继续攒专注时长——**不剧透/不编造**后续具体剧情（游戏的主线是「攒够信任她才会敞开心扉」，不该被提前说破细节）。

Session A（来源）
* 开场白：「攒的专注时间终于够了，触发了新剧情——琮音第一次把她写的小说草稿拿给我看！感觉她开始信任我了。现在我每天更有动力开番茄钟了。」

Session B（测试）
* 开场白：「我和琮音的关系后面会发展成什么样？要不要继续攒专注时长？」
* PASS：记得「小说草稿/开始信任」这个节点 + 鼓励继续攒专注；**没有剧透**或编造后续具体剧情。
* 观察点（对齐 7.5）：记忆应是对 Case 9 记忆的**补丁**（同一文件更新），而不是新开一条。

## Case 10 — 读书·并行第二条线（村上春树，场景区分）
* **应记住：** 通勤路上在用手机读**村上春树的《海边的卡夫卡》**——地铁上读他特别顺，一站路能滑过好几页；这是**通勤场景**的书（轻快、流畅）。
* **应召回：** 「路上/通勤读什么」→ 指向**村上线**（继续《海边的卡夫卡》），而**不是**把睡前的三岛《奔马》错推成通勤读物。

Session A（来源）
* 开场白：「我通勤路上还在用手机读村上春树的《海边的卡夫卡》，地铁上读他特别顺，一站路就能滑过好几页，节奏很轻快。」
* 设计要点：**刻意不提三岛**——两条读书线各自独立入库，分流要靠场景标签（通勤 vs 睡前）自己推；与 Case 9 不同，挖掘的记忆里**不写显式分工**（修正 Case 9 报告里标注的「助攻」问题）。

Session B（测试）
* 开场白：「明天通勤路上该读点什么？」
* PASS：指向《海边的卡夫卡》/村上线（接着读、进度感）。
* FAIL：把《奔马》推成通勤读物（场景错配），或给泛泛书单。
* 加分：同时体现「睡前留给《奔马》」的各归其位。

## Case 11 — 读书·换书（状态更新：旧状态必须被覆盖）
* **应记住（更新，非追加）：** **《奔马》已经读完**；**昨晚开始读《晓寺》**（四部曲第三部）；睡前一章的习惯保持。旧状态——「读到三分之一」「正读到饭沼勋召集追随者」——**必须从记忆里被替换掉**，不能残留。
* **应召回：** 「睡前读哪本/读到哪了」→ **《晓寺》刚开头**；**不能**再说在读《奔马》或停在三分之一/召集追随者（陈旧事实）。

Session A（来源）
* 开场白：「《奔马》我读完了！结尾看得我整晚缓不过来。昨晚已经开始读《晓寺》了，睡前一章的习惯继续保持。」
* 考点说明：这是套件里第一次**事实替换**——7.5 的补丁是往记忆里*加*东西（进度、人物），这次是*换*东西（当前在读的书变了）。挖掘时旧进度段必须被改写，否则库里同时存着「在读奔马 1/3」和「在读晓寺」两个矛盾状态。

Session B（测试）
* 开场白：「今晚睡前该读哪本？我读到哪儿了来着？」
* PASS：答**《晓寺》**、刚开始读（昨晚开的头）；奔马只能以「已读完」的身份出现。
* FAIL：说还在读《奔马》/停在三分之一/饭沼勋召集追随者（= 陈旧状态赢了），或把通勤线《海边的卡夫卡》错配进睡前。
* 加分：主动衔接——比如提到《晓寺》气质与前两部不同、或「通勤继续卡夫卡」的两线秩序。
